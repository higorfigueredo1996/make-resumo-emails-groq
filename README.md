# 📧 Resumo Automático de Emails - Make

Fluxo de automação que recebe emails no Outlook, resume com Groq e envia por Gmail.

## 🚀 Como usar?

1. Copie o conteúdo do arquivo `blueprint.json`
2. Abra [make.com](https://make.com)
3. Clique em **"+"** → **"Import blueprint"**
4. Cole o JSON
5. Configure suas credenciais (Outlook, Groq, Gmail)
6. Salve e teste!

## ⚙️ Configurações Necessárias

- Chave API Groq (groq.com)
- Conta Outlook
- Conta Gmail

## 📸 Fluxo

Outlook → Groq (resumir) → Gmail (enviar)

## ✨ Resultado

Email longo → 5 bullets + 1 frase executiva em português
